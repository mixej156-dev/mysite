# Design Direction — LONAR ECO.

Статус: **утверждено** — вариант A «Clearing House» + кольца роста из варианта C (только в калькуляторе и связанных с ним блоках).
Отклонённые варианты (B «Validator Floor», C «Compound») — в истории git, коммит `a311e3c`.

## Бриф одной строкой

Сайт и демо-кабинет стейкинг-платформы. Аудитория — состоятельные частные держатели крипты и небольшие фонды, которым важно «не казино, а инфраструктура». Главная задача страницы — за 10 секунд передать: *это надёжно, прозрачно, и понятно, сколько я получу*.

## Идея

Институциональный, редакционный, спокойный. Стейкинг подаётся как финансовый продукт с отчётностью: сайт ощущается как хорошо свёрстанный годовой отчёт фонда. Цвет живёт в данных и действиях, не в декоре.

## Палитра (базовые значения)

| Токен | Hex | Роль |
|---|---|---|
| `ink` | `#0B1424` | основной тёмный фон |
| `ink-raised` | `#14203A` | поверхности на тёмном |
| `paper` | `#F2F3EF` | светлый фон (холодная бумага, не крем) |
| `graphite` | `#5B6472` | вторичный текст, приглушённая строка заголовка |
| `cobalt` | `#335CF0` | единственный акцент: CTA, активные линии графиков, focus |
| `rule` | `#D5D8DE` / `#24304A` | границы light / dark |

Семантика: success `#1F9D6B`, warning `#C98A12`, danger `#D64545` (для текста на тёмном — осветлённые версии в токенах).

> Уточнение относительно черновика: cobalt сдвинут с `#3E6BFF` на `#335CF0`, чтобы белый текст на кнопке проходил WCAG AA (≈5.3:1). Для текста-ссылок на тёмном фоне — осветлённый `#8AA6FF`.

## Шрифты

- Sans: **Geist** — всё: заголовки (600, трекинг −2% на крупных кеглях), лиды, текст статей, интерфейс; line-height текста 1.6; длина строки ≤ 72 знаков.
- Mono: **Geist Mono** — только цифры, суммы, адреса, хеши. Все цифры `tabular-nums`.
- Курсива и шрифта с засечками нет (решение заказчика 2026-10-21: прежний Source Serif 4 в лидах читался как курсив; до этого — Schibsted Grotesk + Source Serif 4 + IBM Plex Mono).

## Форма и глубина

- Радиусы: 16 (карточки, модалки), 10 (поля, мелкие элементы), pill (кнопки, бейджи, хедер).
- Тонкие 1px rule-линии; глубина за счёт смены поверхности, тени почти не используются (только у плавающих: хедер, dropdown, модалка, toast).

## Сетка и выравнивание

- Контейнер 1280 + поля 24/40/64. 12 колонок, асимметрия 7/5 в hero и ключевых секциях.
- Контент по левому краю. По центру — только заголовки-разделители секций.
- Чередование тёмных и светлых секций: секция может принудительно включить противоположную тему (`tone="inverse"`).

## Запоминающиеся элементы

1. **Hero главной** — манифест слева, справа «книга выплат»: лента моковых начислений по эпохам, строки мягко подъезжают раз в 2–3 с. Единственная фоновая (не вызванная пользователем) анимация на странице.
2. **Кольца роста** (из C) — концентрические SVG-кольца, каждое = год стейкинга; в центре растёт сумма по выбранному APY. Используются в `/tools/calculator` и в CTA-блоке калькулятора на главной.

```
┌──────────────────────────────────────────────────────────┐
│ ◯ Brand   Staking  Tools  Company  Docs        [Log in]  │  pill-хедер
├──────────────────────────────────────────────────────────┤
│                                   ┌─ Epoch 48 213 ─────┐ │
│  Staking, kept                    │ ETH  +0.0041  09:12│ │
│  to account.        (graphite)    │ SOL  +0.18    09:12│ │
│                                   │ ATOM +0.62    09:11│ │
│  Lead, 2 lines max.               │ ...  (лента)       │ │

```

## Движение

- Easing единый: `cubic-bezier(0.22, 1, 0.36, 1)`; длительности 160 / 280 / 480 мс.
- Движение — ответ на действие пользователя (открыть, раскрыть, подтвердить). Без «fade-up на каждой секции».
- `prefers-reduced-motion` → без смещений и счётчиков, только opacity.

## Чего не делаем

- Фиолетово-розовые градиенты, неон, «стекло» повсюду, тени под каждой карточкой.
- ALL CAPS-лейблы над каждым заголовком, акцент одного слова цветом, стрелка «→» в каждой кнопке.
- Номера 01–05 — только для реальных последовательностей (4 шага стейкинга, timeline).
- Копирование текстов, логотипов, иллюстраций, названий продуктов референсов.
