# Design Direction — {BRAND_NAME}

Статус: **ждёт выбора** (A / B / C или гибрид). После выбора этот файл сокращается до одного утверждённого направления и становится источником токенов для Этапа 2.

## Бриф одной строкой

Сайт и демо-кабинет стейкинг-платформы. Аудитория — состоятельные частные держатели крипты и небольшие фонды, которым важно «не казино, а инфраструктура». Главная задача страницы — за 10 секунд передать: *это надёжно, прозрачно, и понятно, сколько я получу*.

## Что берём из референсов (только принципы)

Все 10 скриншотов в `/references` — Ondo Finance (сайт, app, Private Client, Learn). Spreadefi в папке нет — его принципы (4 шага, пулы, ежедневные выплаты) берём только из CLAUDE.md.

- Типографика как главный инструмент: крупный центрированный display-заголовок в 2 строки, вторая строка приглушена серым. Body — **антиква** (serif), интерфейс — гротеск, цифры в графиках/бейджах — моно.
- Нейтральная база (чёрный / белый / светло-серый #F1F1F1) + **один цветовой акцент на продукт** (фиолетовый у TVL, зелёный у OUSG). Цвет живёт в данных, не в декоре.
- Сетка ~1440 контейнер, широкие поля, bento-раскладка «слева продукт, справа 3 карточки метрик». Радиусы крупные (~20–24px), вложенные карточки в «подложке».
- Плавающий pill-хедер, который меняет тему (тёмный на светлой секции, светлый на тёмной).
- Чередование: fullscreen фото/видео → белые секции → тёмная секция Trust (01–05) → белые.
- Движение: marquee логотипов, карусели с кнопками ‹ ›, «тикер» слов в баннере, графики с точками/столбиками, которые дорисовываются.

## Общее для всех трёх вариантов (не обсуждается)

- Тёмная база + светлые секции, одна акцентная краска + нейтрали, светлая/тёмная тема.
- Display + Text — две явно разных гарнитуры; моно — только для цифр, адресов, хешей. Все цифры `tabular-nums`.
- Шкала отступов 4/8. Easing единый: `cubic-bezier(0.22, 1, 0.36, 1)`; длительности 160 / 280 / 480 мс. `prefers-reduced-motion` → без смещений, только opacity.
- Не используем: фиолетово-розовые градиенты, неон, «стекло» повсюду, ALL CAPS-лейблы над каждым заголовком, стрелку «→» в каждой кнопке.
- Номера 01–05 — только там, где контент реально последовательность (4 шага стейкинга, timeline). Принципы Trust — списком без номеров, если они не упорядочены.

## Вариант A — «Clearing House»

**Идея.** Институциональный, редакционный, спокойный. Стейкинг подаётся как финансовый продукт с отчётностью, а не как крипто-игрушка. Ближе всего к духу Ondo, но холоднее и «бумажнее»: как годовой отчёт фонда.

**Палитра**

| Токен | Hex | Роль |
|---|---|---|
| `ink` | `#0B1424` | основной тёмный фон (глубокий чернильно-синий, не чёрный) |
| `ink-raised` | `#14203A` | поверхности на тёмном |
| `paper` | `#F2F3EF` | светлые секции (холодная бумага, не крем) |
| `graphite` | `#5B6472` | вторичный текст, приглушённая строка заголовка |
| `cobalt` | `#3E6BFF` | единственный акцент: CTA, активные линии графиков |
| `rule` | `#D5D8DE` / `#24304A` | границы light / dark |

Семантика: success `#1F9D6B`, warning `#C98A12`, danger `#D64545`.

**Шрифты**
- Display/UI: **Schibsted Grotesk** (600 для заголовков, плотный трекинг −2%).
- Text: **Source Serif 4** (body, лиды, цитаты; line-height 1.6).
- Mono: **IBM Plex Mono** (APY, суммы, адреса).

**Форма.** Радиус 16 (карточки) / 999 (кнопки-pill). Тонкие 1px rule-линии, тени почти нет — глубина за счёт смены поверхности.

**Запоминающийся элемент.** Hero: манифест слева, справа «книга выплат» — вертикальная лента реальных (моковых) начислений по эпохам, строки мягко подъезжают раз в 2–3 с. Это показывает главное обещание («выплаты каждый день») вместо абстрактной картинки.

```
┌──────────────────────────────────────────────────────────┐
│ ◯ Brand   Staking  Tools  Company  Docs        [Log in]  │  pill-хедер
├──────────────────────────────────────────────────────────┤
│                                   ┌─ Epoch 48 213 ─────┐ │
│  Staking, kept                    │ ETH  +0.0041  09:12│ │
│  to account.        (graphite)    │ SOL  +0.18    09:12│ │
│                                   │ ATOM +0.62    09:11│ │
│  Serif lead, 2 lines max.         │ ...  (лента)       │ │
│  [Start staking]  [See pools]     └────────────────────┘ │
├──────────────────────────────────────────────────────────┤
│ TVL  │ Assets │ Paid out 30d │ Validators   (rule-линии) │
└──────────────────────────────────────────────────────────┘
```

Выравнивание: по левому краю, асимметричная 12-колоночная сетка (7/5). Центр — только у заголовков секций-разделителей.

**Риск:** самый «безопасный» — без хорошего контента может показаться сдержанным/скучным.

## Вариант B — «Validator Floor»

**Идея.** Инженерный, точный, «приборный». Стейкинг — это работа узлов, эпох и блоков; сайт ведёт себя как хорошо сделанный измерительный прибор. Плотнее Ondo, больше данных на экран, но с той же дисциплиной.

**Палитра**

| Токен | Hex | Роль |
|---|---|---|
| `graphite` | `#101413` | основной тёмный фон (зеленовато-графитовый) |
| `panel` | `#181D1C` | поверхности |
| `bone` | `#ECEDE8` | светлые секции |
| `smoke` | `#7D8682` | вторичный текст |
| `amber` | `#F2A93B` | единственный акцент: «индикатор», активные состояния, линии графиков |
| `hairline` | `#2A302E` / `#D2D5CF` | сетка и границы |

Семантика: success `#3FAE7A`, warning = amber-darker `#B87A16`, danger `#E0594B`.

**Шрифты**
- Display/UI: **Archivo** — в заголовках широкое начертание (wdth 125, 700), в интерфейсе обычное (wdth 100). Одна семья, два «голоса».
- Text: **Archivo** 400 (body) — сознательно одна семья для строгости.
- Mono: **JetBrains Mono** (цифры, хеши, таблицы).

**Форма.** Радиус 6 — маленький и единый; видимая модульная сетка из hairline-линий на тёмных секциях, метки осей у графиков. Тени не используются.

**Запоминающийся элемент.** Hero — «карта валидаторов»: поле из ~400 квадратных ячеек, которые загораются amber по мере подтверждения блоков текущей эпохи; при наведении ячейка показывает узел и uptime. Одна оркестрованная анимация, дальше всё статично.

```
┌──────────────────────────────────────────────────────────┐
│ ▣ BRAND │ Staking │ Tools │ Company │ Docs │    [Log in] │  хедер-полоса с hairline
├────────────────────────────┬─────────────────────────────┤
│ STAKE WITH                 │ ▪▪▪▪▪▪▪▫▫▪▪▪▪▪▪▪▪▫▪▪▪▪▪▪▪▪ │
│ MEASURED                   │ ▪▪▪▪▫▪▪▪▪▪▪▪▪▪▪▪▪▪▪▪▫▪▪▪▪▪ │
│ CONFIDENCE  (Archivo wide) │ ▪▪▪▪▪▪▪▪▪▪▪▪▫▪▪▪▪▪▪▪▪▪▪▪▪▪ │
│                            │ epoch 48 213 · 71% signed  │
│ [Start staking] [Docs]     │                             │
├──────┬──────┬──────┬───────┴─────────────────────────────┤
│ TVL  │ APY  │ Nodes│ Uptime 99.9x%      (ячейки-приборы) │
└──────┴──────┴──────┴─────────────────────────────────────┘
```

Выравнивание: строго по левому краю, видимая сетка; таблицы и цифры выровнены по правому краю колонок.

**Риск:** может уйти в «терминал для разработчиков» и оттолкнуть нетехническую аудиторию; светлая тема требует аккуратности, чтобы amber читался (на светлом используем `#B87A16`).

## Вариант C — «Compound»

**Идея.** Тёплее и человечнее, для частного инвестора. Центральная метафора — сложный процент: кольца роста, кривые, которые «наращиваются». Ondo-уровень воздуха и крупной типографики, но с более мягкой, органичной графикой.

**Палитра**

| Токен | Hex | Роль |
|---|---|---|
| `night` | `#0A0F1E` | основной тёмный фон (глубокий индиго-чёрный) |
| `dusk` | `#141B2E` | поверхности |
| `mist` | `#EEF1F5` | светлые секции (холодно-серый) |
| `slate` | `#6A7385` | вторичный текст |
| `glacier` | `#7CC7F2` | единственный акцент: кольца роста, CTA на тёмном |
| `glacier-deep` | `#1D6FA3` | тот же акцент для светлой темы (контраст AA) |

Семантика: success `#34A37A`, warning `#D39B2A`, danger `#D9534F`.

**Шрифты**
- Display: **Bricolage Grotesque** (оптический размер 96, 600; характерные формы букв в крупном кегле).
- Text/UI: **Figtree** (400/500, нейтральный и тёплый).
- Mono: **Geist Mono** (цифры).

**Форма.** Радиус 24 (крупные блоки) / 14 (вложенные) — две ступени, как у Ondo, но иерархия осознанная. Мягкие тени только у плавающих элементов (хедер, модалки).

**Запоминающийся элемент.** Hero — концентрические «годовые кольца» (SVG), каждое кольцо = год стейкинга; при скролле кольца нарастают, а в центре сумма растёт от $10 000 до итоговой по выбранному APY. Тот же визуальный язык потом переиспользуется в калькуляторе.

```
┌──────────────────────────────────────────────────────────┐
│        ( ◯ Brand  Staking  Tools  Company   [Log in] )    │  плавающий pill
│                                                          │
│                Let your crypto                           │
│                keep working.      (центр, 2 строки)      │
│                                                          │
│                    ◯◯◯◯◯◯◯                               │
│                 ◯◯  $12 486  ◯◯     (кольца роста)        │
│                    ◯◯◯◯◯◯◯                               │
│           [Start staking]   [Try calculator]              │
├──────────────────────────────────────────────────────────┤
│  ┌ Pool card ─────────┐ ┌ TVL ────────────────────────┐  │
│  │ ETH  4.1% APY      │ │ ▁▂▂▃▄▅▆▇ (дорисовка)          │  │  bento
│  └────────────────────┘ └─────────────────────────────┘  │
└──────────────────────────────────────────────────────────┘
```

Выравнивание: hero и заголовки секций по центру; содержимое секций — по левому краю.

**Риск:** самый «маркетинговый»; при неаккуратной реализации холодный голубой на индиго может выглядеть типовым fintech.

## Сравнение

| | A Clearing House | B Validator Floor | C Compound |
|---|---|---|---|
| Тон | институциональный, редакционный | инженерный, точный | тёплый, понятный |
| Близость к Ondo | высокая | средняя | средняя |
| Плотность | средняя | высокая | низкая |
| Акцент | cobalt | amber | glacier |
| Body | serif | sans (одна семья) | sans |
| Радиус | 16 / pill | 6 | 24 / 14 |
| Сильная сторона | доверие | отличие от конкурентов | конверсия в калькулятор |

## Рекомендация

**A**, с одной деталью из C: кольца роста как графический язык калькулятора (`/tools/calculator`). A лучше всего соответствует задаче «показать инвесторам институциональное качество», а serif-body — то, что реально отличает Ondo от типовых крипто-сайтов. B стоит выбрать, если продукт позиционируется для технической аудитории / собственных валидаторов.
